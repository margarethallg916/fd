# 个人知识库（类 IMA，可分享 / 订阅 / 公开）

> 父任务 10-21-personal-knowledge-base · 基线：`margarethallg916/fd` main（= 123zhaozheng/kunxiaozhi main @ 1498b534）
> 参考实现：xerrors/Yuxi（交互逻辑、解析/分块/排队/检索/工具），只移植子集。
> 用户定稿（2026-10-21）：见下方「决策记录」。

## Goal

在左侧导航新增「知识库」入口。每个用户可以建多个个人知识库（个数等由管理员管控），上传文档后自动解析、分块、嵌入、建索引；知识库可以按工号分享给指定同事，也可以公开到「知识广场」供他人订阅；昆小智在对话中可以检索用户可访问且已启用的知识库并给出引用来源。模型、OCR、Embedding、Rerank 全部由管理端配置，用户侧不可见。

## 交付拆分（子任务 = 叠加 PR）

1. `10-21-kb-core-ingestion`：核心入库链路（上传→解析→分块→嵌入→Qdrant 混合索引）、任务队列、知识库列表/详情/文档管理/分块预览/检索测试、管理端知识库设置（总开关、并发等）。
2. `10-21-kb-share-subscribe-quota`：分享（工号 + 角色）、公开/知识广场/订阅、审核与下架、RoleLimits 配额、文件库导入/转到知识库、站内通知。
3. `10-21-kb-agent-tools`：昆小智知识库工具（列库、检索、按行打开原文、文档内定位、按文件名搜、存入知识库[需确认]）、对话启用开关、`@知识库`、引用来源卡片。
4. `10-21-kb-graph`：图谱抽取（Mongo 三元组）、图谱增强检索、图谱可视化。

## 全局约束

- 遵循 `.trellis/spec/` 中前后端规范；UI 复用本项目组件与样式（WorkBuddy 风格，卡片禁止渐变 banner）。
- 不新增 Neo4j / Milvus / MinIO 等服务；对象存储复用项目现有存储抽象。
- 所有接口做权限校验：库主 / 编辑者 / 查看者 / 订阅者 / 管理员。
- 不破坏现有 Dify 知识库、文件库、记忆等功能；现有测试保持通过。
